Plan: recursion_train パイプライン(データ作成+学習 / 生成 / 評価)

Date: 2026-08-19 | Status: pending-approval

概要

ロバスト性評価シナリオ(frag_num / dup_frags / attach_point_num)で 生成に成功した分子(curated_data.tsv の valid_smis_on_frags)を訓練データに 累積追加し、rffmg × t5chem(finetuning)モデルを再学習して、再度4条件(normal + 3シナリオ)で 生成精度を検証する「再帰的自己学習」パイプラインを src/recursion_train/ に構築する。

スコープ / 制約:

  • 対象は rffmg × t5chem × finetuning のみ。frag_method はファイル先頭変数(既定 brics)。sampling は 5times_sampling 固定。
  • ラベル recursion{N}(N=1,2,…)を各スクリプトに渡す。
  • src/recursion_train/ 以外の src/ は変更しない。既存コードは subprocess 起動 or import で再利用。
  • 既存 build_augmented_dataset.py / .sh は削除して新規作成。
  • 汎用関数(func.utility.BASEPATH、make_datasets.load_file/save_file、func.evaluation_func.*)を再利用。

出力パス({sampling} は入れない):

種別パス
datadata/rffmg/{frag}/recursion/recursion{N}/(train=累積拡張、val/test=normal コピー)
modelmodels/rffmg/t5chem/finetuning/{frag}/recursion/recursion{N}/best_model
resultsresults/rffmg/t5chem/finetuning/{frag}/recursion/recursion{N}/beam/{scenario}/

成功例の収穫元: recursion1 → normal baseline results/rffmg/t5chem/finetuning/{frag}/5times_sampling/beam/{scenario}/curated_data.tsv、 recursion{N≥2} → 直前ラウンド .../recursion/recursion{N-1}/beam/{scenario}/curated_data.tsv。

運用フロー(手動、ドライバなし): (normal baseline 評価済み) → build_and_train r1 → generate r1 ×4条件 → evaluate r1 ×4条件 → build_and_train r2(r1 の curated を収穫)→ …

実装計画

  1. Step 1: 旧 build_augmented_dataset を削除

    対象ファイル: src/recursion_train/build_augmented_dataset.py, src/recursion_train/build_augmented_dataset.sh

    変更内容: 両ファイルを git rm で削除。__pycache__ 残骸も除去。

    依存関係: なし

  2. Step 2: build_and_train.py(データ作成 + 学習 統合)

    対象ファイル: src/recursion_train/build_and_train.py(新規)

    変更内容: argparse(--frag_method, --recursion_num, --n_select=5, --seed=0。scenarios/sampling/model_ver は固定)。
    データ作成: 収穫元 curated_data.tsv(N==1 は 5times_sampling、N≥2 は recursion{N-1})を読み、nvalid_onfrags==0 はスキップ、ast.literal_eval(valid_smis_on_frags) から random.Random(seed).sample(min(n_select,len)) を抽選。(source,target) で dedup + base train との二重 dedup。base train(N==1 は normal、N≥2 は recursion{N-1})に added を累積して train.* を出力、val/test.* は normal からコピー。added_pairs.csv/augmentation_log.txt も出力。
    学習: subprocess.run で t5chem train --pretrain {BASEPATH}/models/rffmg/t5chem/pretrained --data_dir {recursion{N}} --output_dir {model} --task_type product --num_epoch 50(run_rffmg.sh:29-35 の finetuning 分岐と同一)。
    再利用: func.utility.BASEPATH, make_datasets.load_file/save_file。

    依存関係: Step 1 の後

  3. Step 3: build_and_train.sh(t5chem 環境ラッパー)

    対象ファイル: src/recursion_train/build_and_train.sh(新規)

    変更内容: conda activate t5chem(run_rffmg.sh:8-9 と同じ)、cwd をプロジェクトルートへ。先頭変数 FRAG_METHOD="brics" / RECURSION_NUM=1 / N_SELECT=5 / SEED=0。build_and_train.py を各引数で実行。

    依存関係: Step 2 の後

  4. Step 4: generate.py(1条件生成)

    対象ファイル: src/recursion_train/generate.py(新規)

    変更内容: argparse(--frag_method, --recursion_num, --additional_path {normal,frag_num,dup_frags,attach_point_num}, 生成パラメータ --num_beams=50 / --n_samples=50 / --batch_size=8 / --max_length=256)。 model_dir=models/.../recursion/recursion{N}/best_model、data_dir=既存 data/rffmg/{frag}/5times_sampling/{additional_path}、output_dir=results/.../recursion/recursion{N}/beam/{additional_path}。 gen_rffmg.py の t5chem predict 呼び出しを忠実に再現して subprocess.run で t5chem predict を起動し predictions.csv を生成。時間計測は省略。

    依存関係: Step 3 の後(モデルが必要)

  5. Step 5: generate.sh(t5chem 環境ラッパー)

    対象ファイル: src/recursion_train/generate.sh(新規)

    変更内容: conda activate t5chem(gen_rffmg.sh:5-6 と同じ)。先頭変数 FRAG_METHOD / RECURSION_NUM / ADDITIONAL_PATH="normal"(1条件ずつ、4条件は変数を変え4回実行)。generate.py を実行。

    依存関係: Step 4 の後

  6. Step 6: evaluate.py(1条件評価)

    対象ファイル: src/recursion_train/evaluate.py(新規)

    変更内容: argparse(--frag_method, --recursion_num, --additional_path)。 func.evaluation_func から sc3_check_genmol_results, loadTrainSmiles, calcPhysicProp を import。 outfd=results/.../recursion/recursion{N}/beam/{additional_path}、predictions={outfd}/predictions.csv、test.source=既存シナリオ、 novelty 基準 train = 拡張後 data/.../recursion/recursion{N}/train.target(loadTrainSmiles)。 evaluation.py __main__ の rffmg グルー(predictions を test.source に行番号 join → fragment 列付与 → genmols 構築 → sc3_check_genmol_results(skipCreateExcel=True, n_chunks=5) → stats.csv → calcPhysicProp で physic_property.csv)を忠実に複製(evaluation.py は編集しない)。

    依存関係: Step 5 の後(predictions が必要)

  7. Step 7: evaluate.sh(safe 環境ラッパー)

    対象ファイル: src/recursion_train/evaluate.sh(新規)

    変更内容: 評価は datasets 依存のため safe 環境(run_cpu.sh:6 と同様 ~/miniconda3/envs/safe/bin/python 直呼び、または conda activate safe)。先頭変数 FRAG_METHOD / RECURSION_NUM / ADDITIONAL_PATH="normal"(1条件ずつ、4回実行)。evaluate.py を実行。

    依存関係: Step 6 の後

前提 / 注意

  • recursion1 を回す前に、normal baseline(t5chem finetuning)の3シナリオ評価(curated_data.tsv)が済んでいること(本計画の対象外)。
  • コードスタイル(CLAUDE.md): 型ヒント必須、Google style docstring、import 順、単純変換は lambda、無駄な抽象化/コメントを作らない、乱数 seed 明示、SMILES バリデーション省略しない。
  • 実装は承認後 implementer に委譲。main ブランチへ直接コミット(worktree・作業ブランチは作らない)。
