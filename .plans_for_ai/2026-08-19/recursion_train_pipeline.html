Plan: recursion_train パイプライン(データ作成 / 訓練 / 生成 / 評価)

Date: 2026-08-19 | Status: pending-approval (rev.3 — リーク回避方式)

概要

ロバスト性シナリオ(frag_num / dup_frags / attach_point_num)で 生成に成功した分子(valid_smis_on_frags)を訓練データに累積追加し、 rffmg × t5chem(finetuning)を再学習→再生成→再評価する「再帰的自己学習」パイプラインを src/recursion_train/ に構築する。

リーク回避の核心(rev.2 からの是正)

旧設計は「シナリオ test のフラグメント集合 F → 分子 M」ペアを train に追加しつつ、同じ F で test しており train↔test が重複していた。rev.3 は (B) 方式:

  1. 成功ペア(F→M)を train のみに累積追加。
  2. 3シナリオの test を make_datasets.py の該当ロジックを複製して再生成(拡張後 train.source と dedup、target 空)。 → train に入った F は自動除外、新 test は train と重複しない。
  3. normal は baseline 固定(再分割しない)。ただし 生成分子と同一の分子が val/test にあれば val/test から除去(train へは移さない)。
  4. frag_order は作らない。SAFE/promptsmiles/fraggpt 用データも作らない(rffmg のみ)。

制約: rffmg × t5chem × finetuning のみ、sampling='5times_sampling' 固定、 frag_method は .sh 先頭変数(既定 brics)、src/recursion_train/ 以外は変更しない、汎用関数を再利用。 make_datasets.py は import しない(先頭で datasets を import するため t5chem 環境で失敗し得る → シナリオ生成ロジックは複製)。

recursion{N} データレイアウト(build_dataset.py が生成)

data/rffmg/{frag}/recursion/recursion{N}/
├── normal/            train=前ラウンドtrain + 成功ペア(F→M)(累積),
│                      val/test=前ラウンドval/test から「分子が成功集合の行」を除去
├── frag_num/          test.*=make_datasets複製で再生成(target空)
├── dup_frags/         test.*=同上
└── attach_point_num/  test.*=同上
  • 累積起点: N==1 → baseline 5times_sampling/、N≥2 → recursion/recursion{N-1}/。
  • 収穫元 curated: N==1 → 5times_sampling/beam/{scenario}、N≥2 → recursion/recursion{N-1}/beam/{scenario}。
  • シナリオ再生成の unique_frags.csv は分子が増えないため baseline 5times_sampling/unique_frags.csv を流用。

出力パス

種別パス
